## 3. Lỗi đóng gói phát hiện được (P1)

**D1. Image thiếu `tools/` ⇒ admin resolver luôn 503 trong Docker.**
`server/app.py` nạp resolver bằng `importlib.util.spec_from_file_location("resolve_admin", ROOT / "tools" / "resolve_admin.py")`. `Dockerfile` chỉ `COPY server`, `web`, `data/provinces*` → `/app/tools` không tồn tại → `OSError` → handler trả 503 "Không đọc được gazetteer" (thông điệp gây hiểu nhầm là lỗi dữ liệu).

Đã kiểm chứng:
```
docker exec -u 0 atlas-drill sh -c 'ls /app/tools'   → No such file or directory
docker exec -u 0 atlas-drill python -c 'sqlite3 open gazetteer' → open OK, 14.174 admin_unit
```
Dữ liệu và quyền đọc **không** phải nguyên nhân; nguyên nhân là thiếu file code trong image. Smoke `/api/health` của CI hiện tại không phát hiện được vì chỉ kiểm tra một endpoint.

**D2. `tools/backup_database.py` chỉ backup atlas, không backup gazetteer.**
Gazetteer là thành phần bắt buộc cho `/api/admin/resolve` và `/api/places?admin=1`; thiếu nó thì tính năng suy giảm âm thầm (503). Ngoài ra tên file gazetteer trong bộ corpus-lock là `gaz-*.sqlite3` (không phải `gazetteer-*.sqlite3`) — dễ trượt khi viết runbook/glob.

**D3. Chế độ suy giảm chưa phân biệt nguyên nhân.**
Cùng một 503 cho: gazetteer chưa build, thiếu file code, lỗi đọc, lỗi schema. Không có `degraded` flag trong `/api/health` để người vận hành biết tính năng admin đang tắt.
